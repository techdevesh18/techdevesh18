### ✈️ AeroxDB — Airline Database Management System

> A fully normalized relational database system designed for airline operations, analytics, and reporting.

**🔧 Tools:** `MySQL` · `SQL` · `Power BI` · `DAX`

🔗 **GitHub:** [Aerox_Database_Management](https://github.com/deveshdubey18/Aerox_Database_Management)

- ✈️ Designed a fully **normalized MySQL database** for airline operations covering fleet management, crew assignments, bookings, and revenue analytics with **9 interconnected tables**
- 🔐 Enforced **referential integrity** using Foreign Keys, ENUMs, and CHECK constraints across all tables
- 📊 Built operational queries for **fleet maintenance, crew compliance, and punctuality SLA monitoring**
- 📈 Developed analytical dashboards for **profit by currency** and **passenger satisfaction by travel class**
- 🎯 Enabled airline operations teams to make **faster, evidence-based scheduling and route-profitability decisions**
